# 📊 Vrinda Store Annual Sales Analysis (2022)

## 🎯 Project Objective
The goal of this project is to analyze the annual retail sales data of Vrinda Store for the year 2022. By evaluating customer purchasing behavior, regional performance, and sales channels, this interactive dashboard provides actionable business insights to help optimize future sales strategies.

## 🛠️ Tools & Technologies Used
* **Microsoft Excel:** Data Cleaning, Data Processing, Advanced Pivot Tables, Data Visualization, and Interactive Dashboard Design.

## 📂 Project Files
* `Vrinda_Store_Annual_Report_2022.xlsx` - The main Excel file containing raw data, working pivot tables, and the final interactive dashboard.
* `Vrinda_Store_Dataset.csv` - The raw data extracted for analysis.

## 📈 Key Business Insights
Based on the data analysis, here are the key findings:
* **Target Demographics:** Women contribute to **64%** of total sales, with Adult Women (~35%) being the highest revenue-generating segment.
* **Top Performing States:** **Maharashtra** leads the chart with ₹2.99M in sales, followed closely by Karnataka (₹2.65M) and Uttar Pradesh (₹2.10M).
* **Top Sales Channels:** **Amazon (35%)**, Myntra (23%), and Flipkart (22%) drive the vast majority of the orders.
* **Operational Efficiency:** A massive **92%** of all orders were successfully delivered.
* **Peak Sales Month:** **March** recorded the highest sales revenue for the year (~₹1.93M).
